How Verity works

Verity reconciles what the ledger records against what actually moved through the bank and wallet accounts, quarter by quarter and month by month, then chases the documents needed to clear whatever doesn't agree.

The workflow

  1. Accounts — set up every bank, wallet and ledger source. Add more at any time.
  2. Upload data — statements and ledger extracts. Each file is hashed; transactions are filed into their own month automatically.
  3. Balances — enter opening and closing figures. The system checks the statement foots, each opening agrees to the prior closing, and no period is missing.
  4. Reconcile a quarter — runs each month through the match cascade: reference exact, reference fuzzy, value plus date plus party, value plus date, description similarity, then split and aggregation. Every match records how it matched.
  5. Exceptions — everything unmatched or suspicious gets an automatic reference and enters the clearance queue.
  6. Document requests — raise a referenced request against any exception, print or email the memo, chase it, record the response. Accepting the documents clears the exception.
  7. Quarter rationale — write the analysis, sign it off, and it locks into the cumulative case file.

References

Everything is referenced for later retrieval: exceptions as {{ e.code if e else 'SGE' }}-Q2-23-EXC-0001, requests as -DR-0001, documents as -DOC-000001, tasks as -T-0001.

Roles

Forensic Lead and Finance Reviewer run reconciliations, sign off quarters, assign tasks and clear exceptions. Assistants upload data, enter balances, chase requests and file documents. Viewers read only. Administrators manage users. Every action is written to the audit trail with its before and after value.

A missing document is a gap to be explained, not proof of wrongdoing on its own. Put each material item to the individual concerned for a response before drawing conclusions.
